# БӘЙГЕ v2 — Render
1. GitHub: загрузите все файлы.
2. Render → New → Web Service.
3. Build Command: npm install
4. Start Command: npm start
5. После deploy откройте https://ВАШ-САЙТ.onrender.com/screen
6. Игроки сканируют QR или открывают /phone.
7. На LED нажмите Space для старта.
8. Таймера нет. Первый на финише побеждает.
9. Safari: игрок нажимает «Разрешить движение» после входа. HTTPS Render обязателен.
